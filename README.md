## GitHub Pages 로 올리는 법

1. github.com → **New repository** → 이름 `trip` 등으로 만들고 **Public** 선택
2. 저장소 첫 화면의 **uploading an existing file** 을 눌러 `index.html` 과 `memo.jpg` 를 끌어다 놓고 Commit
3. **Settings → Pages → Source: Deploy from a branch → main / (root)** 저장

1~2분 뒤 `https://<깃허브아이디>.github.io/trip/` 로 열립니다.
수정할 때는 `index.html` 을 다시 올리면 됩니다.
